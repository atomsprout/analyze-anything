Know what is inside any app, installer or file.看清任何应用、安装包和文件里面有什么。

A finding describes that one file and says how sure it is. It is not a verdict on the project: “low” and “medium” order the reading, and many such findings are ordinary choices of a build. The files were only read, never run.每条结论说的是那一个文件，并注明有多确定。它不是对项目的评判：“低”“中”只是阅读的先后，其中很多是构建时的普通选择。这些文件只被读取，没有被运行。

A report you can check一份可以核对的报告

It does not ask you to trust it. Each finding says how sure it is and points at the bytes it came from.它不要求你相信它。每条结论都写明有多确定，并指向它所依据的字节。

  • Honest about confidence. Verified, derived or heuristic. A heuristic says it may be wrong.如实标注置信度。已验证、推导或启发式。启发式的结论会说明自己可能有误。

  • Seven formats. HTML, PDF, Markdown, plain text, JSON, SARIF and CycloneDX.七种格式。HTML、PDF、Markdown、纯文本、JSON、SARIF、CycloneDX。

How it works工作原理

One pass, read only. Every output format is written from the same report, so they always agree.只读地走一遍。各种输出格式都出自同一份报告，所以它们永远一致。

1

Input输入

Any file or folder. It is only read, never run or installed.任意文件或文件夹。只读取，不运行，不安装。

→
2

Unpack解包

Containers are opened layer by layer, within fixed limits.容器一层层打开，受固定的限额约束。

→
3

Analyze分析

Each file goes to the analyzers that understand it: content, binary, Apple, Android, Windows.每个文件交给认识它的分析器：内容、二进制、Apple、Android、Windows。

→
4

Correlate关联

Files are related to one another: what signs what, what contains what.把文件之间的关系对起来：谁签了谁，谁包含谁。

→
5

Report报告

Findings with evidence and confidence, plus what could not be read. Seven formats.带证据和置信度的结论，以及没能读到的部分。七种格式。

Two ways to use it两种用法

The same engine underneath: one input gives the same report in both.底下是同一套引擎：同一个输入，两边得到相同的报告。

>_

Command line命令行

For scripts and CI. Compare two versions with diff, fail a build with --fail-on high.适合脚本和 CI。用 diff 对比两个版本，用 --fail-on high 让构建失败。

▣

Desktop app桌面版

For macOS. Drop a file, read the report, click evidence to see its bytes, keep a history.用于 macOS。拖入文件，读报告，点证据看字节，保留历史。

◎

For AI agents给 AI agent

A read-only MCP server lets an agent look things up in a report.一个只读的 MCP 服务，让 agent 在报告里查东西。

Optional · off by default可选 · 默认关闭

Let an AI walk you through the report让 AI 带你读报告

Add --ai and a model explains the report in plain words. It sees the report, never your files. Every statement must cite findings of the report; those that do not are dropped.加上 --ai，模型会用通俗的话解释报告。它看到的是报告，不是你的文件。它的每句话都必须引用报告里的结论，引用不成立的整句丢掉。

Install安装

Released for Macs with Apple silicon. On other systems, build the command line from source.目前发布 Apple 芯片 Mac 的版本。其他系统请从源码构建命令行。

# the command line命令行
$ brew install atomsprout/tap/analyze-anything

# the desktop app桌面版
$ brew install --cask atomsprout/tap/analyze-anything-desktop

# then然后
$ analyze-anything <file or folder文件或文件夹>
# from source, with Rust 1.90 or newer从源码构建，需要 Rust 1.90 或更新版本
$ git clone https://github.com/atomsprout/analyze-anything
$ cd analyze-anything && cargo build --release
